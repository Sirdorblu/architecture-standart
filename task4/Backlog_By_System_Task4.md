# Backlog по системам (Task4)

## АБС
- Включить роли БО депозитов/кредитов для правки ставок и аудит изменений.

## Сервис справочника ставок
- Поднять Spring Boot сервис, REST GET `/rates`, `/version`
- Кэш 5–15 мин, троттлинг к АБС, метрики и алерты, ограничение p95/p99.
- Опциональный кэш в MS SQL для стабильности.

## Шлюз выгрузки партнёру
- Файл `.sha256` с хешем, PGP подпись/шифрование письма, ретраи.
- Мониторинг доставок, отчёты, регламент ротации ключей, тестовые письма.

## Система КЦ
- Экран «Ставки».

## Партнёрский КЦ
- Импорт CSV, валидации, проверка SHA‑256, обработка ошибок и уведомления.

## Интернет‑банк и Сайт
- Переход на read‑only API справочника ставок, единая версия/TTL с КЦ.

## Инфраструктура/Безопасность
- TLS1.2+/1.3, HSTS, почтовый шлюз, управление секретами.
- Мониторинг, алерты, дашборды, DR-тесты и нагрузочные прогоны.
